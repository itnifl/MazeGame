# Project Status

## Overview

This module contains the living status for the Maze Game project. It tracks scope, requirements, progress, and open tasks.

## Location

Primary file:

```
project-status/project.status.md
```

## How to update

1. Open the status file in your editor.
2. Add new items or adjust the progress sections.
3. Commit with a clear message.
4. Push to the main branch or create a pull request.

## Suggested structure

* Goals and scope
* Deliverables and deadlines
* Current progress
* Risks and mitigations
* Action items with owners

## Conventions

* Keep entries short and clear.
* Date stamp notable changes.
* Link to related pull requests and issues when useful.

## Build or runtime impact

This module does not produce code or artifacts. It is documentation only.
